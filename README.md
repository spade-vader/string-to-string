# String To String - Mouline Thread Comparison App
A mobile application that helps cross-stitch enthusiasts match and compare threads from different manufacturers.

## Features
- Find the closest thread color from different manufacturers.
- Compare thread colors across multiple brands side by side.
- Easy-to-use interface with intuitive navigation.
- Add your threads to Shelf, so you won't forget to buy it!
- Multi-language (rus/eu for now).
